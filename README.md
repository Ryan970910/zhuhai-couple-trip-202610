## 已確定的選擇

- 首選桔子酒店（珠海國際會展中心十字門華發商都店），珠海市香洲區會展五路521號23層。大樓入口及接待樓層按酒店入住指引。備選全季灣仔口岸國際會展中心店：會展一路160號。
- 訂16日入住、19日退房三晚；17日凌晨約00:40–01:30到店，須取得保留16日晚房確認。
- 17日只玩海洋王國、煙花收尾；不加飛船樂園或長隆秀。煙花時間待當日公告，因天氣取消便提前回酒店。
- 單園門票包含一般展館、機動設施、常規表演及普通區煙花觀賞；快趣達、尊享導覽、特別體驗、餐飲商品寄存租借等另計。另兩項需另買票或明確包含的套票。
